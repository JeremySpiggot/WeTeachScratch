# WeTeachScratch

Open-source HTML5 learning platform for teaching people how to code in Scratch through a large library of creative, project-based courses.

## Brand

This project uses the README logo and a bright educational palette inspired by the SVG branding: blue, aqua, purple, orange, and warm yellow accents.

## Features

- Scratch-first curriculum for complete beginners
- Project-based lessons that teach logic, art, animation, and game design
- A growing catalog of course tracks from essentials to advanced game creation
- Open-source HTML5 app that can run locally or be extended by the community

## Course Tracks

1. Scratch Basics
2. Game Design Fundamentals
3. Variables and Logic
4. Loops and Conditions
5. Sprites, Costumes, and Animation
6. Sound and Music
7. Storytelling with Scratch
8. Physics and Movement
9. Platformers and Side-Scrolling Games
10. RPG Systems and Inventory
11. Multiplayer and Remote Collaboration
12. Advanced Game Development

## Local Development

Open `index.html` in a browser, or serve the folder with any simple static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
